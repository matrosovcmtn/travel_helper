# 🇯🇵 Travel Helper — Токио 2026

Интерактивный планировщик поездки: маршрут по дням, бюджет, **настоящая карта** (Leaflet + OpenStreetMap) и чеклист с сохранением отметок.

## Запуск

```bash
npm install      # один раз
npm run dev      # дев-сервер с hot-reload → http://localhost:5173
```

Сборка прод-версии: `npm run build` → папка `dist/` (можно открыть через `npm run preview`).

## Структура

```
src/
  main.jsx              точка входа
  App.jsx               шапка + переключение вкладок
  theme.js              палитра
  data/
    days.js             маршрут по дням + бонусные места
    budget.js           бюджет + расчёт итогов
    locations.js        точки на карте (координаты, категории, границы)
  components/
    PlanTab.jsx         маршрут (раскрытие дней, переключатель погоды)
    BudgetTab.jsx       бюджет
    MapTab.jsx          карта Leaflet/OSM с маркерами по категориям
    ChecklistTab.jsx    чеклист (отметки хранятся в localStorage)
```

## Идеи для расширения

- Фильтр карты по дню / маршрутные линии между точками
- Экспорт маршрута в PDF / Apple Calendar
- Реальные данные погоды и курсов валют по API
- Бэкенд для совместного редактирования вдвоём
